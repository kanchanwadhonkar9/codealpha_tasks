# Task 2 – Linear Regression from Scratch

CodeAlpha Data Science Internship

## What it does
- Implements Linear Regression **from scratch** using only NumPy (no sklearn LinearRegression)
- Gradient descent optimization with cost (MSE) tracking
- Generates synthetic data, trains the model, and plots:
  - Cost history over epochs
  - Regression line vs actual data
  - Actual vs predicted scatter
- Prints evaluation metrics: MSE, RMSE, R²

## Run
```bash
python linear_regression_scratch.py
```

## Requirements
```bash
pip install numpy matplotlib
```
