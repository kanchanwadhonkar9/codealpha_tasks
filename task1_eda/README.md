# Task 1 – Exploratory Data Analysis (EDA)

CodeAlpha Data Science Internship

## What it does
- Generates a synthetic housing dataset (fully self-contained – no external CSV needed)
- Performs univariate analysis (distributions, boxplots, missing values)
- Performs bivariate analysis (correlation heatmap, scatter plots)
- Saves summary statistics and plots to `outputs/`

## Run
```bash
python task1_eda.py
```

## Outputs
- `outputs/summary_statistics.csv`
- `outputs/missing_values.csv`
- `outputs/correlation_matrix.png`
- `outputs/distributions.png`
- `outputs/scatter_matrix.png`
